# אינק סטודיו – אתר לסטודיו לקעקועים

אתר React (Vite) המבוסס על תבנית אתר המוסך, עם תוכן ועיצוב מותאמים לסטודיו לקעקועים.

## הרצה
```bash
npm install
npm run dev      # פיתוח
npm run build    # בנייה ל-dist (פריסה ב-Netlify מוגדרת ב-netlify.toml)
```

## לפני שעולים לאוויר
1. **כתובות שרת** – ב-`src/config/endpoints.js` ברירות המחדל הן של פרויקט המוסך המקורי
   (פניות, התחברות, תמונות, שמירת תצורה). צרו `.env` לפי `.env.example` עם כתובות משלכם,
   אחרת פניות הלקוחות של הסטודיו יישמרו באותו מקום שבו נשמרות פניות המוסך.
2. **ריפו GitHub** – עורך האתר (`/edit`) שומר את `siteConfig.js` לריפו בשם `tattoo-studio`
   (ניתן לשינוי ב-`VITE_GITHUB_REPO`). צרו ריפו בשם הזה או עדכנו את השם.
3. **סיסמאות** – ל-`/upload` יש סיסמה קבועה בקוד (`UPLOADER_PASSWORD` ב-`ImageUploader.jsx`) –
   החליפו אותה. הבדיקות בצד הלקוח אינן אבטחה אמיתית.
4. **תוכן** – כל הטקסטים (שם, טלפון, כתובת, שעות, ביקורות) הם דוגמאות ב-`src/data/siteConfig.js`.
   הביקורות בדויות – החליפו בהמלצות אמיתיות.
5. **תמונות** – הגלריה ותמונת הפתיחה הן איורי דוגמה ב-`public/` (`gallery/*.svg`, `hero.svg`).
   החליפו בצילומי עבודות אמיתיים (כתובת תמונה ב-`gallery.images`).
